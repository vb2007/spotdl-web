## 2. `yt-dlp-ejs` is pinned while `yt-dlp` floats

`backend/Dockerfile` runs `uv pip install --system --no-cache-dir --upgrade yt-dlp`, which upgrades
**only** yt-dlp. `yt-dlp-ejs` stays at `0.8.0` from `requirements.txt`.

yt-dlp-ejs is the companion package that solves YouTube's PO-token challenge — the exact mechanism
whose absence caused the v23 outage. A future yt-dlp release requiring a newer yt-dlp-ejs would
therefore reproduce the identical symptom (`AudioProviderError` → swallowed by spotdl → no output
file), with the added confusion that the "yt-dlp floats now" policy would appear to have already
covered it.

**Fix**: upgrade both together in the same step. Extend the CI freshness check to compare
yt-dlp-ejs against PyPI as well, so a divergence is visible before it's an outage.

## 3. New job never appears in the Jobs list until a full refetch

**Reported from production, mechanism confirmed by code reading.**

`frontend/src/lib/stores/queue.ts:490` — `patchPageJob` bails on `if (idx === -1) return p`, so a
job that isn't already in the current page is silently dropped. The sequence:

1. Submit a job → it goes into the `incoming` overlay while `expanding`.
2. Expansion finishes → `applyJobEvent` sees `expanded`, **removes it from `incoming`**, then calls
   `patchPageJob`.
3. `patchPageJob` finds no matching row in the page (it's a brand-new job) and does nothing.
4. The job is now in neither the overlay nor the list — it has vanished.

It reappears only on a full page refetch, which is why switching scope to Tracks and back made it
show up as `settled`.

**Fix**: a job leaving the `incoming` overlay must be *inserted* into the page when it isn't already
there and it matches the active filters, not merely patched. Respect the current sort — a new job
belongs wherever the active ordering puts it, not unconditionally at the top — and respect the
active filters, so a job that doesn't match the current view correctly doesn't appear.

Watch the interaction with cursor pagination: inserting into a paginated page must not duplicate a
row that a later page already holds, and must not silently push a row off the end without the count
reflecting it.
